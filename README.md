* Strengthen my understanding of algorithms and programming concepts

## Exercises

The current repository contains the following exercises:

* **Addition** – Basic input, output, variables, and arithmetic
* **Greatest Common Divisor** – Euclidean Algorithm and modulo operations
* **Matrix Exploration** – Multi-Source Breadth-First Search (BFS) and shortest paths
* **Word Ordering** – Custom sorting, comparators, and lexicographical ordering
